## 2. 环境与可复现方式

```bash
# 构建（必须 linux/amd64；镜像内装好 contest_harness SDK）
docker build --platform linux/amd64 -t {{repo}}:{{tag}} .
# 导出未压缩 tar（不要 gzip / 不要 zip / 不要源码 tar）
```

平台运行契约（本队据此实现，供复现核对）：

| 路径 | 权限 | 用途 |
|---|---|---|
| `/app` | 只读 | 选手代码、SDK、`/app/harness.py` |
| `/data/train.jsonl`、`/data/validation.jsonl` | 只读 | 当前阶段公开投影 |
| `/previous` | 只读 | 本轮父产物 |

| `/model` | 只读 | 预测时挂载的选中产物 |

```bash

python3 /app/harness.py train
python3 /app/harness.py predict
```
